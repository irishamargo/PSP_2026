## Цель работы

Цель данной лабораторной работы:

- знакомство с инструментами построения пользовательских интерфейсов web-сайтов: HTML, CSS. В ходе выполнения работы, вам предстоит ознакомиться с кодом реализации простого калькулятора, и затем выполнить задания по варианту

## Начало работы

Зайдите в свою локальную директорию с репозиторием для выполнения лабораторных работ. Заберите ветку с соответствующей лабораторной работой из общего репозитория:

```sh
git pull upstream
```

**или**

```sh
git pull upstream calculator_visual
```

Переключитесь на ветку с текущей лабораторной работой:

```sh
git checkout calculator_visual
```

Свяжите ветку локального репозитория с вашим удаленным репозиторием:

```sh
git push --set-upstream origin calculator_visual
```

## Задание

1. Создание калькулятора
2. Верстка на HTML, CSS
3. Копировать 3-5 основных цветов кодами с сайта по вашей теме (хедер, фон, карточки, кнопки, hover) и еще 2-3 свойства (padding и тд)

---
## Указания по выполнению лабораторной работы

- Все изменения вносятся в файлы calculator.html и style.css
- CSS-правила добавляются в существующий файл стилей
- HTML-элементы добавляются в существующую структуру калькулятора
- Для проверки открывайте файл в браузере после каждого изменения

---

## Требования к реализации
- Работа должна быть выполнена в файлах calculator.html и style.css
- Все изменения должны быть реализованы с использованием только HTML и CSS (допускается минимальное использование JavaScript для пунктов 12, 17)
- Калькулятор должен сохранять свою основную функциональность (кнопки должны нажиматься, результат отображаться)
- Внешний вид должен быть уникальным и не повторяться с работами других студентов


## Пример программы

Основные HTML теги, использованные в работе

```html
<!-- Основная структура -->
<div class="calculator">              <!-- Контейнер калькулятора -->
<div id="result" class="result">0</div>   <!-- Поле вывода результата -->

<!-- Кнопки с разными классами -->
<button class="my-btn secondary">C</button>      <!-- Вторичные кнопки (C, +/-, %) -->
<button class="my-btn primary">/</button>        <!-- Основные кнопки операций -->
<button class="my-btn execute">=</button>        <!-- Кнопка выполнения (шире) -->
<button class="my-btn backspace">Backspace</button>  <!-- Кнопка с широким форматом -->

<!-- Дополнительные кнопки -->
<button class="my-btn secondary">√</button>      <!-- Квадратный корень -->
<button class="my-btn secondary">x²</button>     <!-- Возведение в квадрат -->

<!-- Переключатель темы -->
<button id="theme-toggle" class="theme-btn">Темная тема</button>

<!-- Шапка сайта -->
<div class="header">
    <span class="metro-title">Московский<br>метрополитен</span>
    <h3> Схема </h3>
    <h3> Как оплатить </h3>
    <a href="contacts.html" style="text-decoration: none;">
        <h3> Контакты </h3>
    </a>
</div>

<!-- Подвал -->
<footer class="footer">
    <h2>ЛР выполнена Маргориной Ириной</h2>
</footer>
```
CSS-переменные для тем

```css
:root {
    --bg-color: white;           /* Цвет фона для светлой темы */
    --text-header: black;        /* Цвет текста для светлой темы */
    --result-color: rgb(73, 73, 73);
    --theme-btn: rgb(17, 19, 128);
    --theme-honor: rgb(48, 51, 227);
}

[data-theme="dark"] {
    --bg-color: rgb(32, 32, 32); /* Цвет фона для тёмной темы */
    --text-header: white;         /* Цвет текста для тёмной темы */
    --result-color: #a6a6a6;
    --theme-btn: rgb(241, 232, 106);
    --theme-honor: rgb(235, 231, 168);
}
```
Стилизация кнопок
```css
.my-btn {
    margin-right: 5px;           /* Отступ от кнопки справа */
    margin-top: 5px;             /* Отступ от кнопки сверху */
    width: 50px;                 /* Ширина кнопки */
    height: 50px;                /* Высота кнопки */
    border-radius: 50%;          /* Округление кнопки (полностью круглые) */
    border: none;                /* Отключаем обводку */
    background: #a6a6a6;         /* Серый цвет по умолчанию */
    color: var(--bg-color);      /* Цвет текста (зависит от темы) */
    font-size: 1.5rem;           /* Размер шрифта */
    cursor: pointer;             /* Курсор-указатель при наведении */
}

/* Стили для кнопки "=" */
.my-btn.execute {
    width: 110px;                /* Шире обычных кнопок */
    border-radius: 34px;         /* Скругление как у таблетки */
}

/* Стили для кнопки Backspace */
.my-btn.backspace {
    width: 110px;
    border-radius: 34px;
    font-size: 1.2rem;
}

/* Эффект при наведении */
.my-btn:hover {
    background: #636363;         /* Затемнение */
}

/* Эффект при нажатии */
.my-btn:active {
    filter: brightness(130%);    /* Эффект вспышки */
}
```
